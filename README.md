# 오늘의 영어 학습 (Daily English Quiz)

매일 아침 자동으로 새 콘텐츠가 배포되는 영어 학습 웹앱(PWA)입니다.

**앱 주소:** https://park-minjoo.github.io/daily-english-quiz/

## 폰에 앱처럼 설치하기

- **iPhone (Safari):** 위 주소 접속 → 하단 공유 버튼 → "홈 화면에 추가"
- **Android (Chrome):** 위 주소 접속 → 우측 상단 ⋮ → "앱 설치" 또는 "홈 화면에 추가"

설치하면 홈 화면 아이콘으로 전체화면 실행되고, 오프라인에서도 마지막에 본 내용을 볼 수 있습니다.

## 구성

| 파일 | 역할 |
|---|---|
| `index.html` | 앱 본체. 맨 아래 `const DATA = {...}` 블록이 매일 교체되는 콘텐츠입니다. |
| `manifest.json` | PWA 설정 (앱 이름, 아이콘, 테마 색) |
| `sw.js` | 서비스 워커. 네트워크 우선 + 오프라인 폴백 |
| `history.json` | 지난 학습 기록. 표현·주제 중복 방지용 |
| `icon-*.png` | 앱 아이콘 |

## 학습 흐름 (약 30분)

1. **워밍업 퀴즈** — 단어·숙어 문제를 먼저 전부 풀기 (정답 즉시 공개 안 됨)
2. **정답 & 풀이** — 한번에 채점 + 표현별 뜻·예문 해설
3. **오늘의 대화 주제** — 앱에서 주제 확인 → Claude 앱에서 영어로 대화
4. **마무리 피드백** — 대화 중 문법·표현 교정

콘텐츠는 매일 아침 8시(KST) Claude 예약 작업이 자동으로 갱신합니다.
